# Code of Conduct

## Our standard

Be constructive and respectful. We're building a directory for a shared ecosystem — criticism of code, content, or bots is fine; personal attacks, harassment, trolling, and spam are not.

## Scope

This applies to the repository (issues, PRs, discussions) and any project spaces, including the submission pipeline.

## Enforcement

Maintainers may remove, edit, or reject comments, issues, PRs, and listings that violate this standard, and may ban repeat offenders. Report problems via the contact on the [about page](https://grokbothq.xyz/about).
