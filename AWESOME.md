# Awesome Grok Bots

> A curated list of the best Bots from the [Grok Bot](https://docs.x.ai/grok-bot/overview) share ecosystem — the always-on teammate Bots from xAI, each with its own persistent cloud computer. Maintained by [GrokBot HQ](https://grokbothq.xyz), an independent directory of **2,407 published Bots**.

Grok Bot is the always-on AI teammate, not grok.com chat, Grok Imagine, or a Grok model writeup. Every entry below is a live, public `x.ai/bot` share link.

## Why this list is short

The directory behind it holds 2,407 published Bots. This list is the **80** that clear a bar, across 8 categories, because a list that includes everything tells you nothing. The full, searchable directory is on the site.

**How entries are chosen** (stated so you can disagree with it):

- Every entry is a published Bot with a working `x.ai/bot` share link.
- Where an install count exists it leads — but only 54 of 2,407 Bots expose one publicly, so installs cannot be the only signal.
- Remaining places go to Bots whose builder is already known for shipping, and whose own description actually explains the job the Bot does.
- Nothing is ranked by payment, and no builder can buy a place.
